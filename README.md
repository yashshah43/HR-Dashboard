# HR Dashboard
This repository contains an interactive Tableau Dashboard designed to assist Human Resources teams in analyzing and managing employee data. The dashboard provides both a high-level overview and detailed insights into employee metrics.

## 📊 Dashboard Overview
The HR Dashboard consists of two main sections:

### 1. HR Summary
This dashboard offers a comprehensive overview of key HR metrics, allowing stakeholders to monitor organizational trends effectively. Key features include:

Employee Distribution: Visualizations showcasing the distribution of employees by department, location, and gender.
Attrition Analysis: Insights into employee turnover rates with trends over time.
Department-Wise Metrics: Highlights of department-specific KPIs, such as average tenure, headcount, and performance scores.
Salary Insights: Overview of salary distribution across departments and roles.
Diversity and Inclusion Metrics: Analysis of workforce diversity, including gender ratios and representation across teams.

### 2. Employee Details
This section provides granular insights into individual employees, focusing on their:

Demographic information (age, gender, location, etc.).
Performance ratings and trends over time.
Tenure within the organization.
Compensation details.
Training and development metrics.

## 🛠 Features
Interactive and visually appealing design.
Filters for customized data views, including department, location, and job roles.
Drill-down capabilities to analyze detailed employee-specific data.
Real-time trends to support proactive decision-making.

## 📁 File Structure
HR_Dashboard.twbx: The Tableau Workbook file containing all visualizations and configurations.

## 🚀 Getting Started
### Prerequisites
Tableau Desktop or Tableau Reader is required to open and view the .twbx file.

### Steps to Open
Download the HR_Dashboard.twbx file from this repository.
Open the file in Tableau Desktop or Tableau Reader.
Interact with the dashboards to explore the data.
